# 🦊 The Clever Fox's Gem Quest

A magical, kid-friendly color-matching game built with p5.js! 

I created this custom game specifically for my 6-year-old. The goal was to build something that practices reading, color recognition, and focus, all wrapped in a relaxing, forgiving, and beautiful environment.

## ✨ Features
*   **No "Game Over" Screens:** Designed to be stress-free. Missing a gem just creates a gentle puff of dust.
*   **Dynamic Color Switching:** Every 5 correct catches, the target color changes to keep the brain engaged!
*   **Magical Aesthetics:** Features a pixel-art fox, glowing gems, drifting fireflies, and a deep forest background.
*   **Grand Finale:** Reaching 30 points triggers an interactive "You Win!" screen with continuous fireworks.
*   **Smooth Controls:** The fox smoothly follows the mouse cursor, making it very easy for young players to control.

## 🎮 How to Play
1. Look at the instructions at the top of the screen (e.g., "Catch the **BLUE** gems!").
2. Move your mouse left and right to slide the Fox across the bottom of the screen.
3. Catch the falling gems that match the target color!
4. Avoid the wrong colors. 
5. Reach 30 points to trigger the fireworks show! 🎆

## 🛠️ How to Run Locally
To play this game on your own computer:

1. Clone or download this repository.
2. Open the `public` folder in your favorite code editor (like VS Code).
3. If using VS Code, install the **Live Server** extension.
4. Right-click on `index.html` and select **"Open with Live Server"**.
5. The game will automatically open and run in your default web browser!

## 📁 File Structure
*   `index.html`: The main page that loads the game and the p5.js library.
*   `style.css`: Keeps the game centered and removes scrollbars.
*   `sketch.js`: The actual game logic, graphics, and mechanics.
*   `PROMPT.md`: The AI prompts used to generate this game.
